## 张数规划

默认 = 封面 1 + 食材准备 1 + 步骤图 N + **注意事项 1（固定最后一张）**。步骤合并到 ≤5 张（相邻小步合并，如"去皮+改刀"）；注意点既并入对应步骤图（画面表现+短标签），**也**在末张注意事项图汇总。

注意事项图：标题"注意事项"或"小贴士"，4–6 条短句（每条 ≤12 字），取自 recipe.md"容易翻车的点"；**条目前统一用小手绘琥珀色星星标记，禁用红叉**（红叉看着像"错误/禁止"，误导读者）；红×只允许画在被视频明确排除的食材涂鸦上（如蒜/盐碟），不得放在文字条目前；风格与全套一致。

图上信息完整但不堆砌：步骤图包含步骤标题、该步关键信息（用量/时间/火候/替代料/条件规则，取自 recipe.md）、注意点标记——**视频里该步没有注意点就不标，不得编造**。用短句分行（每行 ≤14 字）控制乱码风险，不设死数量上限；乱码就重生成。封面可选文字块（用户要求时）：顶部大标题、食材一行、底部 3 个关键步骤短注。

## 分镜确认（硬门槛）

outline.md 即分镜脚本：每图写 Position / 画面内容 / 图上文字（逐字）/ 并入的注意点。写完后完整呈现给用户（张数表+每图画面与文字），拿到明确确认后才允许写 prompts 与调图像后端；用户要改 → 改 outline 再确认。**未确认不生图。**

## 风格预设

### watercolor-journal（默认，手绘水彩食谱手账）

- 画法：细棕褐钢笔/针管笔勾边，线条粗细轻重变化、局部自然断线；水彩淡彩叠色，不涂满、轻微超线、边缘留纸白。
- 纸张：米白/奶油水彩纸底，细颗粒；水痕晕染与沉积，上色不均、可见笔触方向；手工不完美感，非矢量平涂/数码渐变。
- 色彩：暖调低饱和高明度；奶油黄/琥珀/赭石主色；一小块高纯对比色（约一成，如番茄红）提神；线稿深棕褐。
- 光线：左上柔和漫射；高光留白/薄涂；暗部淡灰紫冷调一层；无硬投影。
- 视角：近俯视约 70°，轻微透视见器物高度与底沿；全画面均匀清晰无景深。
- 排版：主图居中，配景对角散布，大留白；顶部深棕手写毛笔大标题，手写小标签稚拙大小不一略歪；点缀空心小星星、四角十字闪光、弧形双线箭头、逗号形水汽。
- 气质：治愈、家常、温暖、克制，像摊开的手绘食谱笔记/儿童绘本。

### comic-unified（统一漫画风）

粗深棕描边+赛璐璐简化造型、轻微手绘质感；参考色板四色（暖黄/橙/sage 绿/柠檬黄）组合成整体视觉而非贴字面色块；食材同风格绘制、色相真实。

### impasto-warm（厚涂暖色）

漫画造型+调色刀厚涂油画笔触；高饱和暖黄/橙/绿；适合想要"色彩灵感板"气质的用户。

用户给参考图时：只提取风格/色板/气质，**不抄排版与文字**；用户文字规格优先于预设。

## 统一风格硬规则

1. 全图同一画法——禁止"背景漫画、食材写实"的混搭。
2. 食材色相取真实颜色（番茄红、肥牛粉白/熟灰褐、金针菇乳白、油菜绿、干豆腐淡黄）。
3. **生熟状态颜色**：焯水后的肉=灰褐熟色，画面任何位置不得出现生粉色（步骤 2 下锅瞬间除外）；肉形态=薄切卷片，非厚切牛排/块。
4. 配景只放菜谱内食材与器具，不引入无关食材。
5. 图上文字逐字给定、手写体、深棕；无英文/ hex /水印/人脸。
6. **溯源硬规则**：图上所有文字与信息必须源自 recipe.md（视频提取）；不得编造注意点、数字、食材或功效。

## prompt 与 outline 格式

`outline.md` frontmatter：type / density / style / palette / language / image_count / aspect；每图一条：Position、Purpose、Visual Content、Filename。

`prompts/NN-{type}-{slug}.md` frontmatter：illustration_id / type / style / palette / references（仅当文件存在于 references/，usage: direct|style|palette）。正文：STYLE 段（预设全文或用户规格）→ LAYOUT（top→bottom，文字逐字用引号给出，含该步关键信息行）→ CAUTIONS（该步注意点，逐字取自 recipe.md；视频没有则省略本段）→ INGREDIENT HUES → TEXT RULES（声明全部字符串源自 recipe.md）→ ASPECT: 3:4。

注意事项图 prompt 要点：标题"注意事项"；4–6 条短句逐字取自 recipe.md"容易翻车的点"（每条 ≤12 字）；每条前统一小手绘琥珀色星星，**禁止红叉放在条目前**；不写长段落；风格段与全套一致。

## 核对与迭代

逐张 Read 核对：文字逐字、生熟/形态、配景一致、风格统一；**每条图上信息溯源 recipe.md，该步注意点标清、视频没有的不得出现**。不合格 → 写 `NN-...-v2.md` 新 prompt + 新输出路径重生成（保留候选供对比），重试一次；构图性错误可换构图描述（如"熟肉已在锅中、漏勺空"比"漏勺捞熟肉"更不易画出生肉）。

交付：`make_gallery.py` 压缩内嵌 ≤1MB；候选清理仅在用户要求时。
