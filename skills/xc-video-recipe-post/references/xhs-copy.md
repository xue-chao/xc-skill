# 小红书文案

## 必须产出与完整性

- 完整流程必须产出 post.md 并在对话贴出全文；仅用户明确只要部分阶段时才跳过。
- 正文完整承载 recipe.md 关键细节：数字、时间、火候、替代料、条件规则、否定规则不得省略；注意事项图的内容也要在正文或小贴士中体现。

## 输出格式

```
### 推荐标题
1–6 个，每个 ≤20 字；数字型/感叹/疑问优先；含高频词（热乎、汤浓、零失败、新手、下饭等按菜调整）

### 正文内容
钩子开场（季节/痛点/场景）→ 食材一行 → 分点步骤（注意点内嵌，关键数字保留）→ 场景化收尾（拌饭/保温/家人反应）→ 提问式互动 + 收藏引导；少量 Emoji 点缀；分段空行

### 推荐标签
5–10 个：菜名 + 品类 + 场景 + 人群（如 #番茄肥牛 #砂锅菜 #暖身食谱 #下饭菜 #新手做饭）
```

正文与 recipe.md 的数字必须一致；可提"步骤画成手绘食谱手账，存图跟着做"作为差异化卖点。
